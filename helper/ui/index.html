    Helper settings

    A page opened from a file has no web address; browsers send it as null, the same label any website can give a hidden sandboxed frame. While this is on, such a page could use this helper. Turn it on only while you need it, or run a local web server instead.

    The website looks for the helper on port 8765. After changing the port, open Helper connection on the website and enter the new address.
